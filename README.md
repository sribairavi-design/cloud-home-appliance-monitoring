# Cloud-Based Home Appliance Monitoring System

## 🚀 Live Demo

**Try the live application here:**  
https://cloud-home-appliance-monitoring.onrender.com

## 📌 Project Description

The Cloud-Based Home Appliance Monitoring System is a web application developed using Python, Flask, HTML, CSS, JavaScript, and SQLite. It allows users to monitor simulated home appliances, view their status, and switch appliances ON or OFF through a web interface.

## ✨ Features

- View home appliance details.
- Monitor appliance status.
- Switch appliances ON or OFF.
- View energy consumption information.
- View simulated room temperature.
- Dashboard with appliance summary.

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## ▶️ Run Locally

1. Clone the repository.
2. Install the required packages using `pip install -r requirements.txt`.
3. Run the application using `python app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

## ⚠️ Note

This project is a simulation for demonstration purposes. It does not directly control real home appliances or use physical IoT sensors.
